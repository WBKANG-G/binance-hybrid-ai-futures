# 2026-11-16 새 복사본·합성 키·주간 경계 검토

USB는 분리 보관하고 원본과 기존 복구 컨테이너는 정지 상태로 유지합니다.
실제 API 키를 입력하지 않습니다. 거래소 통신이나 주문은 실행하지 않습니다.

1. 폴더 전체를 바탕화면에 압축 해제합니다.
2. CMD에서 이 폴더로 이동한 뒤 `RUN_CHECK.cmd`를 실행합니다.
3. `RESTORE_CHECK_PASSED_NO_CLONE_NO_SOURCE_START_NO_ORDERS`가 나온 경우에만
   `RUN_PRIVATE_WEEK.cmd`를 한 번 실행합니다. 70초 이상 대기 단계가 있습니다.
4. 성공 표시는 `PRIVATE_WEEK_SYNTHETIC_VERIFIED_NEW_COPY_STOPPED_NO_ORDERS`입니다.
   출력 전체를 전달합니다. 실패 시 반복 실행하지 않고 출력을 전달합니다.

런타임이 연결되지 않습니다. Docker 로그 저장을 끄고 네트워크를 차단합니다.
모든 새 키 도우미를 정지한 뒤 tmpfs가 비었는지 확인합니다. 새 DB도 정상 정지합니다.
