# 새 복사본 전용 V1 시계 전환 검증

USB를 연결하지 않습니다. 원본·보존된 복구 사본·방금 진단한 복사본도 정지 상태로 둡니다. 이 실행기는 PC 내부 백업과 영수증 3개의 고정 해시를 검증하고, 별도의 새 DB/runtime/socket 복사본을 만듭니다.

먼저 `RUN_CHECK.cmd`로 입력 해시와 정지 범위를 확인합니다. 성공 후 `RUN_CLOCK_REHEARSAL.cmd`를 한 번 실행합니다. 새 복사본의 전체 지문이 방금 성공한 진단 영수증과 같을 때만 V1 CLOCK_REBASE를 명시적으로 실행합니다. 원본이나 기존 복사본에서 실행하지 않습니다.

감사 행과 체크포인트를 각 1건만 추가하고, 기존 행·누적 비용·계좌·일/주 기준·미해결 요청 4개를 보존합니다. V2 연결, 미완료 조회, stopped 플래그, 지문 불일치는 전환 전에 거부합니다. 진단 helper는 네트워크 없음·비 root·읽기 전용 루트이며 새 runtime만 쓰기 가능합니다. DB 쓰기 연결도 같은 새 복사본의 Unix socket으로만 명시적으로 엽니다.

전환 후 최소 70초 기다립니다. `COPY_CLOCK_HOLD remaining_seconds=...`가 표시됩니다. 이후 새 읽기 전용 세션으로 시계, 전체 시작 대기와 기존 데이터 보존을 재검증하고 새 PG 복사본을 정상 정지합니다. V2 연결·날짜 채택·실제 GET·주문·원본 재개는 없습니다.

실패하면 새 복사본의 시계 전환이 완료됐을 수도 있습니다. 임의로 반복 실행·삭제·수리하지 말고 출력과 남겨 둔 영수증을 확인합니다. 입력 백업과 직전 진단 복사본은 변경하지 않습니다. Docker Desktop 엔진만 실행하며 기존 컨테이너는 정지 상태로 유지합니다.
