# 데모 주문 이력 내보내기 요청 — 한 번만 생성

이 패키지는 고객센터 없이 공식 데모 API의 주문 이력 내보내기 지원 여부를 확인합니다.
데모 호스트 지원을 사전에 보장하지 않습니다. 주문 생성·취소·재전송·원장 변경은 없습니다.

1. RUN_CHECK.cmd: 고정된 과거 백업과 진입 주문 대조 기준 2건을 확인합니다. HTTP/키 입력 없음.
2. 확인 성공 후 RUN_REQUEST_EXPORT.cmd를 한 번 실행합니다. 같은 데모 계정의 API Key와
   Secret을 PC의 숨김 입력란에 입력합니다. 입력 문자는 표시되지 않습니다. 채팅에 보내지 마세요.
3. 요청 성공 뒤 RUN_STATUS.cmd는 기존 작업의 상태를 한 번 조회합니다. 같은 키를 숨김 입력합니다.
   상태 조회는 새 내보내기를 만들지 않습니다. 자동 대기·자동 반복은 없습니다.

사용자는 내보내기 생성(GET /fapi/v1/order/asyn)이 다운로드 작업 1개와 월간 한도
1회를 소비함을 확인한 후 RUN_REQUEST_EXPORT.cmd를 실행합니다. SDK 문서 기준
월 10회, 요청 가중치 1000입니다. 프런트엔드와 공유하는 한도이며 잔여 횟수는 알 수 없습니다.
현재 IP 요청 가중치와 exchangeInfo의 분당 한도를 확인하고 1200 여유가 없으면 중단합니다.
동일 IP의 다른 프로그램 사용량을 완전히 통제한다고 주장하지 않습니다. 429/418도 재시도하지 않습니다.

숨김 입력은 프로세스 메모리에서 HMAC 서명에만 사용하고 파일·환경변수·명령줄·로그에
저장하지 않습니다. 현재 사용자/관리자에 의한 메모리 검사에 대한 방어를 의미하지 않습니다.
HTTP는 https://demo-fapi.binance.com 고정, TLS 검증 유지, 리디렉션·LIVE 전환 없음입니다.
키 입력이 끝난 뒤 네트워크 처리 시간 제한 60초를 시작합니다.
서버 시각, 요청 가중치, 과거 두 진입 주문의 원래 client ID 해시·서버 ID·Filled·가격·수량을
대조한 후 생성합니다. 인증 대조 실패 시 내보내기를 요청하지 않습니다.

새 개인 폴더 LOCALAPPDATA\WBKANG-DEMO-Exports는 현재 사용자와 SYSTEM만
허용하는 NTFS ACL을 요구합니다. 키가 아닌 거래소 응답·작업 ID는 비공개 로컬 자료입니다.
콘솔에는 원래 client ID나 다운로드 URL을 출력하지 않습니다. 화면만 공유하고 파일 원문은 공유하지 마세요.

내보내기 생성 직전에 ORDER_EXPORT_ATTEMPT_20261117.json을 새 파일로 기록하고
읽기 검증합니다. 기존 시도 기록이 있으면 새 생성은 거부합니다. 파일을 지워서 재시도하지 마세요.
네트워크 오류/미지원/응답 불명/기록 실패 때도 자동 재생성하지 않습니다. 작업 ID가 저장된
경우에만 RUN_STATUS.cmd가 해당 ID를 조회합니다. 결과는 JOB.json과 STATUS_*.json에 보존합니다.
상태 응답 URL은 비공개 파일에만 저장하고 자동으로 열거나 다운로드하지 않습니다.

구간은 KST 2026-10-20 00:00(UTC 10-19 15:00)부터 이번 실행에서 확인한 서버 시각까지입니다.
현재 키 대조를 위한 최근 서버 시각 범위와 최대 45일 구간을 요구하는 한시적 도구입니다.
서버 시각이 2026-11-16 23:00 UTC 이전 또는 2026-12-03 15:00 UTC 이후면 중단합니다.
모든 과거 자금 이력을 포함하는 구간이라고 보장하지 않습니다.

이 단계는 내보내기 작업 생성·상태 확인까지입니다. CSV 원문 다운로드·분석, 알고 주문 이력,
자금 이력 수집, 과거 요청 해소나 기준금액 채택은 아직 수행하지 않습니다.
기존 원본·복사본은 정지, USB는 분리 상태로 두세요. Windows 파일/ACL 생성은 실제 PC 확인이 필요합니다.
