# 기존 생성 시도를 유지하는 일반·알고 주문 이력 조회

이전 EXPORT_CREATION_OUTCOME_UNRESOLVED 결과에서는 HTTP 200 객체를 받았지만
유효한 문자열 downloadId를 얻지 못했습니다. 기존 도구가 그 응답을 저장하지 않았으므로
데모 미지원인지 ID 자료형 차이인지 지금 확정할 수 없습니다. 기존 내보내기 생성기를
다시 실행하거나 ORDER_EXPORT_ATTEMPT_20261117.json을 삭제하지 마세요.

이 패키지에는 내보내기 생성/상태 경로가 없습니다. /order/asyn, /trade/asyn,
/income/asyn은 전송기 allowlist에서 거부합니다. 기존 guard·작업 파일을 읽거나 수정하지 않습니다.

RUN_CHECK.cmd 성공 후 RUN_READ_HISTORY.cmd를 한 번 실행합니다. 같은 데모 API Key와
Secret을 PC의 숨김 입력란에 입력합니다. 채팅에 보내지 마세요. 키는 파일·환경변수·
명령줄에 저장하지 않습니다. 프로세스 메모리 검사/시스템 관리자로부터의 방어를 뜻하지 않습니다.

서버 시각·exchangeInfo·과거 진입 주문 2건을 확인한 뒤 UTC 2026-10-20 하루의
BTCUSDT /allOrders와 /allAlgoOrders를 각각 한 번 조회합니다. 이 날짜는 남은 종료·손절
요청의 로컬 발생 시각을 포함합니다. HTTP는 최대 6회, GET 전용, 호스트는
https://demo-fapi.binance.com 고정이며 TLS 검증과 리디렉션 금지·자동 재시도 금지를 유지합니다.
가중치 여유가 100 미만이면 목록을 요청하지 않습니다. 계정/IP 전체 사용량 증명은 아닙니다.

현재 사용자/SYSTEM만 허용하는 NTFS 비공개 새 폴더
LOCALAPPDATA\WBKANG-DEMO-HistoryReads\history-read-20261117-*에
REGULAR_20261020.json, ALGO_20261020.json을 보존합니다. HTTP 200 본문은 목록
스키마 검사 전에 UTF8 바이트로 저장·해시 검증합니다. 배열이 아닌 미지원 응답도 여기에
남습니다. 키/Secret 원문이 응답에 들어 있으면 저장 전에 거부합니다. HTTP 오류 본문은
저장하지 않고 고정 HTTP 분류만 출력합니다. 콘솔에는 원문·원래 client ID를 출력하지 않습니다.

결과의 exact_id_candidate_count는 원래 ID 해시와 일치하는 후보 수이며 요청 해소가 아닙니다.
1000행이면 페이지 한도 도달로 표시합니다. 1000행 미만/빈 목록이어도 보관 제한 때문에
전체 이력 완전성이나 과거 미전송을 증명하지 않습니다. 내보내기 작업의 성공/실패도 결정하지 않습니다.

완료/실패 화면만 공유하고 비공개 파일 원문은 올리지 마세요. 실패 시 자동 재실행하지 않습니다.
원본·복사본 정지와 USB 분리를 유지합니다. CSV 다운로드, 자금 내역, 원장 해소,
기준금액 채택·거래 재개는 하지 않습니다. Windows 5.1 양성 실행은 사용자 결과 확인 전입니다.
