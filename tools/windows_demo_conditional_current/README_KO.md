# 최신 DEMO 관측과 승인된 소스 조건 확인

바탕화면에 압축을 풀고 CMD에서 실행합니다.

```cmd
cd /d "%USERPROFILE%\Desktop\windows-demo-conditional-current-20261124"
RUN_CHECK.cmd && RUN_READ_AND_BIND.cmd
```

두 번째 명령에서 DEMO API Key와 Secret을 PC의 숨김 입력창에 입력합니다. 채팅에 보내지 마세요. 입력한 키는 메모리에서만 사용하며 파일·환경변수·명령 인자에 저장하지 않습니다.

DEMO 호스트에 GET 요청만 수행합니다. 표준 경로는 서버 시간 두 번을 포함해 19회입니다. 계정 전체 미체결 일반/알고 주문·포지션, 잔액을 두 차례 관측하고 BTCUSDT 설정과 기존 소득·체결 증빙 이후 내역을 확인합니다. 기존 계정 식별 앵커와 요청량·시간·응답 크기·7일 제한을 유지합니다. 승인 범위는 11월 24~29일, 주차 11월 23일, 금액 4998.74183608 USDT입니다. 이 범위 안에서도 기존 증빙과의 간격이 7일을 넘으면 거부하므로 새 증빙 없이 29일까지 실행할 수 있다는 뜻은 아닙니다.

관측이 5분 이내이고 계정 상태·금액·설정이 일치하며 추가 손익/체결 행 및 포화 페이지가 없을 때만 소스를 연결합니다. 현재 저장한 14개 응답 파일과 기존 증빙 해시를 다시 확인합니다. 결과와 응답 파일은 LOCALAPPDATA의 WBKANG-DEMO-ConditionalReads 아래 비공개 폴더에 보존합니다.

성공 표시는 `CONDITIONAL_SOURCE_BOUND_NO_ORIGINAL_START_NO_APPLY_NO_ORDERS`입니다. 이는 이번 관측에 소스 승인을 연결했다는 뜻입니다. 원본 DB 시작·쓰기, 기준액 적용, 소유권 인수, 과거 미해결 요청 해소·재전송, 주문 실행 권한은 없습니다. Docker를 호출하거나 서비스를 시작하지 않습니다. 앞 단계 파일 비교는 사용자 화면으로 보고된 과거 증거이며 이 도구에서 재실행하지 않습니다. 정확한 자정 평가액·전체 과거 체결 내역이 새로 증명되는 것도 아닙니다.

오류나 조건 불일치 시 자동 재시도하지 않습니다. 같은 명령을 반복하지 말고 결과 화면을 전달하세요. 원본 DB/API/key-session 및 이전 복사본은 계속 정지 상태로 유지하세요.
