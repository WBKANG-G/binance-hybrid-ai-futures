# 원장 복구 오프라인 미리보기

압축을 바탕화면에 풀고 해당 폴더에서 RUN_PREVIEW.cmd를 한 번 실행한다.
키 입력·네트워크 연결·Docker 실행이 필요 없다. USB D:와 원본/복사본 서비스는 그대로 둔다.

고정 백업과 기존 IncomeReads → TradeReads → CurrentReads 영수증을 해시로 연결한다.
현재 조회 원문 14개를 재검사해 두 관측에서 일반/알고 미체결·포지션 부재,
격리 2배·자동 증거금 꺼짐, USDT 잔액 일치, 빈 활동 공백을 확인한다.
현재 원장을 직접 조회하는 도구가 아니며, 고정 백업의 이전 행과 저장 보고서만 읽는다.

후보 일자는 2026-11-18 KST, 주 시작은 2026-11-16이다. 이 날짜의 저장 관측에 대한
후보이며 실행한 날의 최신 잔액을 주장하지 않는다. 실행 시 원장·증거 파일을 쓰지 않는다.
화면 결과에는 기존 금융 구성요소와 누적 고점, 요청 4건의 상태를 보존해 표시한다.
원래 요청 ID 대신 SHA256만 표시한다. 원문 응답이나 키를 채팅에 보내지 않는다.

성공 마지막 줄:
RECOVERY_PREVIEW_COMPLETE_NO_APPLY_NO_HTTP_NO_WRITES_KEEP_STOPPED

성공은 기준금액 채택이나 거래 재개 승인이 아니다. 기존 함수의 7일 앵커 제한을 우회하지
않으며 apply token을 만들지 않는다. 자정 평가액 독립 복원, 전체 종목 과거 이력,
최초 자금, 미확정 요청 처리 결과는 입증하지 않는다. 로컬 영수증 해시 일치는 거래소의
독립 서명이나 과거 자료의 완전성 보증이 아니다. 중복 성공 실행은 선택하지 않고 중단한다.
실패하면 표시된 failure_category만 확인하며 옛 export 생성 guard를 삭제하거나 재시도하지 않는다.
