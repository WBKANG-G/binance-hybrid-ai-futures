# 16일자 합성 키 검토 v2

USB는 분리 보관, 원본·기존 사본은 정지 상태를 유지합니다. 실제 키 입력은 없습니다.

압축을 바탕화면에 풀고 CMD에서 RUN_CHECK.cmd를 실행합니다.
RESTORE_CHECK_PASSED_NO_CLONE_NO_SOURCE_START_NO_ORDERS가 나온 경우에만
RUN_PRIVATE_WEEK.cmd를 한 번 실행합니다. 70초 이상 대기와 자료 검사 단계가 있습니다.
성공 표시는 PRIVATE_WEEK_V2_SYNTHETIC_VERIFIED_NEW_COPY_STOPPED_NO_ORDERS입니다.
실패하면 반복하지 않고 출력 전체를 전달합니다.

기존 실패한 사본은 재사용하지 않습니다. 사용자가 보여준 실패 시점의 도우미 5개 ID가
지금도 정지·네트워크 차단·원본 볼륨 미사용 상태인지 먼저 메타데이터로 확인합니다.
이전 원시 보존 파일 및 성공 영수증의 고정 해시도 재확인한 뒤 새 볼륨만 만듭니다.

자료 준비 단계의 합성 파일 연속성 검사는 서명 권한과 자격증명 객체를 만들지 않습니다.
이 단계는 같은 읽기 전용 tmpfs·파일 FD·잠금·내용 지문·합성 pair·시계와 12시간 파일 만료를
확인하며 최대 300초로 제한됩니다. 실제 서명 직전 단 한 번 새 75초 lease를 엽니다.
75초 제한·시계 검사를 늘리거나 꺼두지 않고, 만료 후 갱신·자동 재시도도 하지 않습니다.
잘못된 pair와 파일 변경은 보조 자료를 쓰기 전에도 거부합니다.

검토 후 모든 새 키 helper를 정지하고 tmpfs가 비었는지 확인합니다. 새 DB도 정상 정지합니다.
저장 일자 13일/주간 9일, 주문 34건·미해결 요청 4건을 유지해야 합니다.
실제 거래소 통신·주문·기준금액 채택·원격 신원 확인·설치 승인은 없습니다.
날짜가 한국 기준 16일이 아니면 새 자원을 만들기 전에 중단합니다.
