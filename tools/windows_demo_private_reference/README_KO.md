# 최신 합성 검토의 로컬 참조 해시 묶음

USB는 분리하고 원본·사본은 정지 상태로 유지합니다. 실제 키 입력이나 Docker 작업은 없습니다.
CMD에서 RUN_CHECK.cmd를 실행해 검사 성공을 확인한 뒤 RUN_CREATE_REFERENCE.cmd를 한 번
실행합니다. 성공 문구는 자동 출력되는 결과이며 입력 명령이 아닙니다. 전체 출력을 보내주세요.

검증된 v3 성공 영수증과 동반 기록을 읽어 다섯 파일의 SHA256, 기존 보존/복구/검토 해시 참조,
알려진 소스 버전과 일부 검토 사실을 새 전용 폴더에 기록합니다. 새 파일은
REFERENCE_MANIFEST.json과 REFERENCE_RECEIPT.json 두 개입니다. Windows의 현재 사용자와
SYSTEM만 접근할 수 있는 NTFS 폴더를 사용하고, 기존 파일을 덮어쓰지 않습니다.

원본 영수증·DB·백업 파일은 변경하지 않습니다. 원본 JSON/응답 원문/키 파일 내용은 복사하지
않고 정해진 필드와 해시만 기록합니다. 생성 파일을 다시 읽고 원본 기록의 해시도 재확인합니다.
실패 시 부분 생성 폴더를 남기고 자동 재시도·정리·덮어쓰기를 하지 않습니다.

이번 결과는 PC 내부 참조 사본입니다. 복구 백업 자체가 아니며 USB 복사·물리적 분리 보관·
별도 PC 검증은 아직 수행하지 않습니다. 서명 또는 원격 계정 신원 증명·기준금액 채택·설치·
주문 승인이 아닙니다. 남은 근거 8개는 미해결로 유지합니다.
