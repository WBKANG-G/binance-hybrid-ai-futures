# 합성 검토 이후 필요한 실제 근거

현재 완료된 것은 합성 키/응답을 사용한 복사본 검토와 로컬 영수증 일치 확인입니다.
아래 항목은 현재 false/미해결 상태입니다. 이 참조 생성으로 완료 처리하지 않습니다.

| 항목 | 필요한 근거와 다음 조건 |
|---|---|
| 계정 신원·자격증명 연결 | 실제 데모 계정과 키 사용 문맥을 연결하는 자료. 키/secret은 채팅·파일·로그에 남기지 않는 별도 준비가 필요합니다. |
| 계정·종목 설정 | 실제 계정의 포지션/마진 모드와 종목 설정 자료. 합성 응답에는 들어 있지 않습니다. |
| 일반·알고 미체결 주문 | 두 종류를 분리한 현재 상태 자료. 합성 잔고나 로컬 포지션 종료 기록만으로 대체하지 않습니다. |
| 거래·수익·입출금 전체 범위 | 검토 구간의 누락 없는 이력·페이지 범위와 원문/감사 연결. 기존 주문이나 요청을 삭제해 범위를 줄이지 않습니다. |
| 일자 경계 평가 | 저장 13일/주간9일에서 검토16일/주간16일로 넘어가는 자정 가치 또는 명시적으로 수락한 재구성 근거. 현재 잔고를 과거 기준금액으로 자동 채택하지 않습니다. |
| 운영자 진술·근거 수락 | 구체적인 계정·구간·근거에 대한 별도 진술과 수락. 단순한 다음 단계 요청이나 파일 선택을 진술·수락으로 처리하지 않습니다. |
| 과거 미해결 요청 4건 | 개별 요청에 연결된 독립 거래소 근거. 로컬 종료·조회 not found·합성 성공만으로 해소하지 않습니다. |
| 현재 기간·손실 기준 재검사 | 실제 원장과 일간/주간 기준·고점/손실 보호를 다시 확인한 결과. 오래된 기간을 단순 리셋하지 않습니다. |

실제 거래소 조회 전에는 별도 읽기 전용 범위, 요청 비용/현재 사용량/공유 IP 용량,
자료 저장·동일 파일 키 사용·시간·계정 문맥 및 실패 시 정지 조건이 필요합니다.
이번 프로그램은 실제 키 입력·거래소 조회·원본 시작·기준금액 채택·주문을 수행하지 않습니다.

최신 참조 해시를 별도 매체에 보관하는 것은 이후 로컬 기록과 대조할 기준을 남기는 일입니다.
이는 위 실제 근거, 복구 백업 또는 별도 PC 검증을 대신하지 않습니다.
