# 오프라인 복구 미리보기 구현

사용자가 현재 계좌 조회 성공 화면을 보내고 다음 단계 진행을 지시했다. 이전 복구 제안을
바탕으로 원장 쓰기와 거래 재개 없이 실행 가능한 Windows 미리보기를 준비한다.

고정 백업 기준·금융 구성요소는 기존 BaselineReference 검증기를 재사용해 읽는다.
IncomeReads → TradeReads → CurrentReads의 intent 참조와 원문 SHA256을 연결한다.
현재 14개 원문을 다시 파싱해 전체 종목 미체결/노출 부재, USDT 잔액 정합성,
두 모드/격리 2배 설정, 빈 income/BTC trades 공백을 확인한다. 요약의 성공 주장만으로
원문 검사를 대체하지 않는다. 부정합, 중복 성공 폴더, 파일 범위 이탈, 링크/해시 불일치는 중단한다.

모든 입력은 읽기 공유 스트림으로 열고 끝에 해시를 다시 대조한다. 백업 tar는 stdout으로
읽으며 추출 파일을 만들지 않는다. PowerShell5의 root array 호환 파서를 고정해서 재사용한다.
기존 폴더의 Windows 보호 DACL, 사용자 소유권 및 reparse 금지 검사를 유지한다.
패키지에는 전송/키 입력/파일 생성/DB/적용 코드가 없다. 순수 파서만 고정 소스에서 추출한다.

화면에는 후보 일·주 기준금액, 이전 스냅샷과 저장 보고서 날짜, 보존할 금융 구성요소·고점,
요청 4건의 기존 상태와 해시, 적용 차단 사유를 출력한다. 원래 client ID·원문 계정 응답은
출력하지 않는다. 7일 초과 기준 시점을 보존하고 기존 함수를 통과시키는 변경을 하지 않는다.

현재 DB는 검증하지 않는다. 실제 적용 diff나 apply token을 만들지 않는다. 11월18일
저장 관측 후보는 실행 당일의 최신 관측을 의미하지 않는다. 자정 평가액·최초 자금·전체 종목
과거 이력·미확정 요청 결과는 여전히 미검증이며 로컬 해시를 거래소 독립 서명으로 표시하지 않는다.
사용자의 무활동 진술을 연장하거나 새로운 진술/기준금액 수락으로 대신하지 않는다.

테스트의 HTTP 대체 입력은 기존 수집 도구로 합성 파일을 만드는 준비에만 사용한다.
미리보기 실행 경로 자체는 네트워크 없이 동작한다. Linux에서는 Windows ACL 양성 경로만
대체하며 실제 Windows5.1 실행과 사용자 원본 파일 검사는 아직 관측하지 않았다.
