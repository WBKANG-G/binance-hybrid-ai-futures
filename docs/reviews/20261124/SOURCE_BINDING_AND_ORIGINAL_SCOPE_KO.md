# 승인된 출처 연결과 원본 정지 범위의 읽기 전용 점검

사용자는 바로 앞의 구체적인 출처/조건부 재사용 수락 질문에 '다음 단계 진행해'라고 답했다.
이 답변을 제시한 범위로 진행하라는 지시로 반영하고 원문 그대로 기록한다. 답변에 없던 '응'
등의 표현이나 정확한 시각을 만들어 넣지 않았다. 당시 KST날짜11/24만 기록했다.
수락은11/24 후보,11/23 시작 주,각4998.74183608 USDT와11/29까지의 제한적 재사용 조건이다.
원본 시작·쓰기·owner/lease 인수·기존 보호 조건 해제·과거 요청 처리·거래 승인은 포함하지 않는다.

새 SOURCE_ACCEPTANCE_RECEIPT.json은 검토 ID/검토안 전체 해시/질문/답변/후보/재사용 조건/
미증명 항목/권한 범위를 묶는다. 이전11/18 수락 기록과 기존 검토안은 변경하지 않는다.
검토안의 activated=false는 수락 전 작성된 불변 문서의 내용이며, 현재 승인은 별도 수락 기록의
conditional_reuse_approved=true로 연결한다. 이는 대화 기록의 내용 연결이며 외부 서명은 아니다.

새 verify_conditional_acceptance는 코드의 고정 지문과 검토안/수락 기록을 비교한다. 입력이
주장하는 해시를 다시 신뢰하지 않는다. 금액/기간/답변/정책을 바꾸거나 원본 쓰기 권한을
추가하면 거부한다. bind_fresh_source는 검증된 수락에 기존 조건 평가를 연결한다.
5분 이내의 신뢰 가능한 서버 시각·검증된 참조 이후7일 이내의 공백·같은 주/금액·새 안정적
무노출 조회가 모두 맞는 경우에만 관측일의 출처 수락을 재사용할 수 있다. 실패를 승인으로
바꾸지 않는다. 긍정 결과도 apply token/원본 쓰기/실제 적용 준비/거래 권한은 false다.
호출자는 실제 응답/참조 파일 해시와 신뢰 가능한 새 서버 시각을 별도로 검증해야 한다.
이번 단계에서 기존11/24의 과거 관측을 신선한 자료로 재분류하지 않았다.

다음 점검 패키지는 이 수락 기록을 연결한 상태에서 고정 백업 입력과 원본 정지 범위만 읽는다.
기존 c5cc610의 영수증 결합 원본 식별/마운트/이미지/재시작/정지 검사와 알려진 helper52의
완전한 RO 격리/종료0 검사를 재사용한다. 그 원본 guard 파일들은 바이트 동일하다.
COPY_CORE와 COPY_EXT는 clone 생성/정지 함수 앞에서 잘라 read-only 정의만 남겼다.
worker/SQL 파일은 넣지 않으며 실행 인자는 ManifestSHA256 하나뿐이다.
잘못된 인자나 전송/수락 기록 변조는 원본 범위 조회 전에 거부한다.

원본 컨테이너나 새 helper/사본을 시작·생성하지 않는다. 입력 파일은 RO 스트림으로 잠그고
처음/잠금 후/범위 확인 후의 백업 해시를 검사한다. 끝에 현재 컨테이너 집합과 상태도 다시
검사하고 스트림을 닫는다. 기존 source나 새 보고 파일을 쓰지 않으며 결과는 화면에만 표시한다.
이 점검은 API 키/네트워크 API/USB가 필요 없다. Docker는 이미 조회 가능한 상태여야 한다.

source_bytes_compared=false, current_original_sql_queried=false,
current_original_fence_verified=false,fresh_account_evidence_checked=false,
conditional_reuse_evaluated=false,original_apply_ready=false를 명시한다.
성공을 원본 데이터 바이트 일치나 현재 SQL/fence/owner 검증으로 확대하지 않는다.
원본용 실제 저장 경로와 권한 인수 정책도 아직 준비/승인되지 않았다.

검사는 기존 조건25건+새 수락 연결16건+원본 사전 점검8건이다. 순수 함수에는 합성 입력을
사용했고, 사전 점검은 실제 PowerShell에서 파일/런처를 실행하되 Docker/원본 상태는 fixture로
대체했다. 실제 사용자 Windows5.1/NTFS/원본 컨테이너 전체 경로는 실행 관측 전까지 미검증이다.
클라우드에서 사용자의 원본/백업/새 응답 원문이나 실제 Binance API에 접근하지 않았다.
