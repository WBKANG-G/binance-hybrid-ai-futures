# 승인된 다음 단계: D: USB에 해시 참조 별도 복사

사용자 최신 Windows 출력에서 로컬 참조 생성 성공이 관찰되었다. 사용자는 이어서 진행하도록 요청했다.
기존 선택 매체는 D: USB/exFAT이고 현재 분리 보관 상태이다. 이번 도구는 다운로드 준비가 끝난 뒤
사용자가 해당 USB를 다시 연결하고 D:임을 확인하여 실행한다.

- V3 읽기 전용 영수증 검토 코드를 성공한 v2 릴리스와 바이트 단위로 동일하게 재사용한다.
- 영수증 5개와 제작 소스 ee8aa302e90ec2b9227e03c557b2a226b78f0289의 로컬 참조 2개를
  연결된 SHA256으로 대조한다. 최대 32개 폴더에서 정확히 한 성공 참조만 허용한다.
- 참조의 허용 필드·이전 핀·권한 비활성 값·정지/정리 기록·기간 기록을 검사한다.
- 원본 영수증 및 참조의 읽기 스트림을 유지하고 복사 전후 길이와 SHA256을 재검사한다.
- D:가 USB, NTFS/exFAT, 비부팅·비시스템·온라인·쓰기 가능 상태이며 여유 공간이 있는지 확인한다.
  실제 장치 식별값의 해시를 복사 전후 반복 대조한다. 원시 장치 식별값은 출력하지 않는다.
- 새 UUID 폴더만 생성한다. 참조 2개와 새 복사 기록 1개를 CreateNew/Flush/readback으로 저장한다.
  기존 백업 및 기타 파일은 수정·삭제하지 않는다. 포맷/자동 재시도/자동 제거도 없다.
- NTFS에서는 사용자+SYSTEM 디렉터리 ACL을 확인한다. exFAT에서는 ACL 검증을 주장하지 않는다.
- 실패 시 부분 복사 폴더를 남기고 종료한다. 원본 및 복구 사본을 시작하지 않는다.

테스트는 Linux PowerShell 7의 합성 영수증과 파일을 사용한다. 성공 경로의 Windows ACL·매체 검색·
USB 경로 경계만 대체한다. 실제 사용자 USB 복사, Windows PowerShell 5.1/NTFS 실행,
물리적 분리 및 독립 외부 보관은 사용자 실행 전까지 관찰되지 않았다.

실행 파일: RUN_CHECK.cmd → 검사 성공 시 RUN_HANDOFF.cmd 한 번.
성공 후 Windows 안전 제거 → 물리적 분리 → 별도 보관이 필요하다.
원본·복구 사본 정지, 실제 거래소 요청/주문 0, 기준값 채택·실행·거래 권한 비활성은 유지한다.
미충족 증빙 8개와 별도 PC 검증 부재는 이번 참조 복사로 해소되지 않는다.
