# 11월5일 일간 기준금 자동 처리

사용자는11월3일 기준금 적용 이후 안내 명령 외 거래/입출금/이체/보너스가 없음을 확인했고, 안전하게 처리 가능한 단계의 자동 진행을 요청했다. 최신 후보는 NORMAL/paused, 11월3일→11월5일, 이전/후보4998.99761493 USDT 동일, 주간/고점/이력 유지다. 계정 전체 거래소 내역 검증 대신 사용자 확인과 서명 USDT 증거를 사용하는 범위다.

압축을 새 폴더에 풀고 ADOPT-NOV5-DAY.cmd가 보이는 위치에서 CMD를 열어 다음 한 번만 실행한다.

```bat
ADOPT-NOV5-DAY.cmd
```

이 파일은11월5일 전용이다. 기존 API 안에서 캐시 키를 사용해 로컬 기간→새 서명 후보→기존 감사된 적용 명령→읽기 전용 준비 확인을 자동 수행한다. 토큰을 화면/클립보드로 옮기지 않는다. 기존 코드를 설치하거나 변경하지 않는다. 새 주문·거래 재개를 하지 않는다.

실제 DB 변경은 기존 명령을 통한 일간 기준일/기준금 및 적용 감사 기록이다. 주간/고점/미해결 요청/위험 상태 보존과 paused 상태를 검사한다. 계정/날짜/금액/증거/보존 조건이 다르면 적용하지 않는다. 이미 현재 날짜면 적용 없이 준비 확인만 한다. 적용 요청 후 오류면 변경됐을 수 있어 자동 재시도하지 않는다. BLOCKED_NO_AUTOMATIC_RETRY면 출력 그대로 공유하고 명령을 반복하지 않는다.

고정 operation ID191e9476-1763-46cb-8c3e-b79f8e31506e를 사용한다. 성공 시 NOV5_DAY_ADOPTED_AND_READY_ENTRIES_STILL_PAUSED 또는 이미 현재인 경우 ALREADY_CURRENT_NO_APPLY를 출력한다. 키/Secret은 출력하지 않으며 숨김 입력도 요청하지 않는다. 세션 만료 시 중단한다. 이 자동 절차는 실제 TP 성공/Phase4 전체 완료/LIVE/Phase5를 포함하지 않는다.
