# DEMO bookTicker 사용량 헤더 처리 — 개발 검토 자료

공식 SDK가 신뢰하지 말라고 명시한 bookTicker 사용량 헤더가 기존 관측치를 덮어쓰거나, 누락 시 실행을 중단시키는 문제를 수정했습니다. 수정 전 5개 실패를 재현했습니다. 이제 낮거나 과도하거나 잘못되거나 누락된 값 모두 사용량·관측 시각의 근거에서 제외합니다.

원본 응답·헤더는 그대로 전달하고, 요청 비용 2는 보존합니다. 기존 신뢰할 수 있는 관측 시각을 갱신하지 않습니다. 새 신뢰 관측 없이 5초가 지나면 기존 차단이 계속 적용됩니다. 418/429·실제 전송 실패·다른 경로의 헤더 누락도 계속 중단합니다. 자동 재시도나 가짜 헤더는 추가하지 않았습니다.

검증: 테스트 1,276개, mypy 156개 소스, Ruff, 네트워크 없는 Docker 스모크 통과. 모의 TP에는 헤더 누락, 부분 체결 청산에는 과도한 헤더 값을 주입해 원래의 전체 청산 확인까지 통과했습니다. 시작 대기는 가속했고 관찰은 0.8초입니다. 새로운 300초 자연 관찰이나 거래소 검증은 아닙니다.

실제 계정 주문 사용량·외부 IP 여유·전체 요청 비용 상한은 미확인입니다. 운영 실행 기본값은 비활성입니다. Windows 설치·Windows DB 변경·실제 거래소 요청·실제 주문·거래 재개는 수행하지 않았습니다. 현재 PC에서 추가 실행할 명령은 없습니다.
