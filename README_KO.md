이번 개선은 전체 청산 비용을 진입 시 한 분에 예약하던 방식을 대체합니다. 모든 요청을 보내기 **전에** 최근 60.001초 자체 모델 비용을 확인하고 **5,700**에서 차단합니다. 발표된 6,000에서 300을 남기며, 진입 전 청산용 512를 별도로 확보합니다. 이전 시험의 가상 한도 100,000을 쓰지 않고 이번 여섯 경로는 모두 가상 한도 **6,000**에서 실제 실행했습니다.

서로 다른 모든 분 시작 시각과 60.001초 반올림 여유 구간을 기존 독립 분석기로 대조했습니다. 최악 값은 여섯 경로 전체에서 **5,332**입니다. 원본 요청열과 분석 결과는 reports/, minute_reviews/, MINUTE_SUMMARY.csv에 있습니다. episode_weight는 누적 비용이므로 한 분 비용과 다릅니다.

## 달라진 동작

- 가격/이력 조회에 예산을 다 쓰기 전에 중단하고, 같은 요청 전 한도 아래에서 시각 조회와 원래 fenced 위험 축소 주문에 도달합니다. 신규 LIMIT 진입 1회와 소유 ID·방향·수량이 제한된 reduce-only 청산 1회만 전송합니다. 응답 유실은 이미 시도한 것으로 남기며 재전송하지 않습니다.
- 원래의 전체 이력 확인보다 물리적 포지션 축소를 먼저 수행합니다. 포지션 0 또는 취소 ACK만으로 장부의 filled/remaining/재무 값을 지우거나 CLOSED/VERIFIED_FLAT를 만들지 않습니다. 남은 진입 주문이 불확실하면 포지션 0이어도 검증 대기를 시작하지 않습니다.
- 최종 성공은 기존 전체 역사 검증과 원래 5회 스냅샷을 거쳐야 합니다. 확인할 자원이 부족하면 포지션 0인 상태에서 lease를 갱신하고 관찰하며 대기합니다. DB 잠금이나 단일 확인 context 안에서 자원을 기다리지 않습니다. 완료된 확인은 최대 4회, 자원 대기는 최대 120초로 제한합니다.
- 실패한 취소가 계속 불확실하면 UNKNOWN 및 일시정지를 유지합니다. 폭주 후 청산 검증이 성공해도 실패한 TP 시험을 성공으로 바꾸지 않습니다. 별도 budgeted_flat_confirmation만 VERIFIED_FLAT입니다.

## 검증과 범위

서로 겹치지 않는 선택 검증 **924개 통과**: 단위/핵심 회귀 896개, 위 통합 경로 6개, 별도 불확실 취소 통합 경로 22개입니다. 별도 집중 회귀 111개도 통과했으며 그중 89개는 앞 단위 시험과 중복되므로 이중 집계하지 않았습니다. Ruff 및 mypy(141개 운영 Python 소스)가 통과했습니다.

과거 설치 가드의 단위 시험 3건이 직전80f에서도 현재 파일 해시 때문에 실패하는 점을 확인했습니다. 이 시험들만 고정된 합성 소스 트리를 사용하도록 격리하고, 파일 변조 시 DB 접근 전에 차단하는 검증을 추가했습니다. **운영 설치 가드의 해시·정책은 바꾸지 않았습니다.** 기존 가드를 이 새 소스에 그대로 재사용할 수 있다는 뜻은 아닙니다.

모든 HTTP/주문/체결은 FakeDemo, WSS는 localhost, PostgreSQL은 분리 스키마입니다. 실제 거래소 요청·주문·Windows DB 접근은 모두 0입니다. 실거래와 실제 DEMO 실행은 기본 거부하며 새 활성화 CLI는 없습니다. 기존 TP CLI를 자동으로 새 경로로 바꾸지 않았습니다. 따라서 이 ZIP은 **검토용 전체 소스 및 증거**이며 Windows 설치나 거래 재개 명령을 포함하지 않습니다.

실제 거래소 비용 상한·공유 IP 용량·별도 주문 횟수 제한은 아직 증명하지 않았습니다. 외부 IP 작업, 헤더 손실, HTTP429 또는 거래소 장애가 발생하면 청산 확인이 UNKNOWN으로 남을 수 있습니다. 이번 측정은 모델 통합의 진전이며 실제 운영 성공을 증명하지 않습니다.

## 파일과 오프라인 재계산

source/는 고정된 Git 소스(기존 배포 ZIP과 의존성 tar.gz 2개 제외), integration.patch는 직전 후보 대비 변경, test-results/는 JUnit·정적 검사 결과입니다. SOURCE_PROOF.json에 원래 청산 및 전체 확인의 AST 보존과 기본 CLI·운영 설치 가드 보존을 기록했습니다. TRANSFER_MANIFEST.json은 자기 자신을 제외한 모든 파일 SHA256입니다. .cmd/.bat/.ps1/.exe는 없습니다.

```text
python review_tp_minute_budget.py reports/delayed.json --limit 6000 --reserve 300
```

위 분석기는 HTTP·DB·주문 기능이 없는 오프라인 도구입니다. source/docs/TP_BUDGET_INTEGRATION.md에 구현 구조와 재현 방법이 있습니다.
