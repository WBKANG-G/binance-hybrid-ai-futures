# DEMO 주문 예약 내구성 개발 검토 자료

검토용 소스와 검증 결과입니다. Windows 설치 파일이나 거래 재개 도구가 아닙니다.

- 같은 DEMO 원장과 공유 저널을 사용하는 프로세스의 동시 진입을 차단합니다.
- 흐름당 6슬롯을 전체 청산 확인까지 보존하며, 전송 직전 별도 디스크 커밋으로 역할을 한 번만 소비합니다.
- 강제 종료와 PostgreSQL 롤백 후에도 이미 소비한 전송 권한을 돌려주지 않습니다.
- 저장소 누락·변조·기록 불일치는 신규 진입을 막습니다. 자동 초기화나 복구 명령은 없습니다.
- 실제 계정 주문 사용량은 여전히 UNKNOWN이며, 실거래 실행 기본값은 비활성입니다.

테스트 1,070개(중복 제외), mypy 147개 소스, Ruff 통과. 네트워크 없는 Linux Docker 저장소 재개 스모크도 통과했습니다.
실시간 70.001초 대기와 300초 관찰을 사용한 모의 TP/시간 종료 청산의 60.001초 요청 가중치 최고치는 각각 4,648 / 4,319였습니다(상한 5,700).
부분 체결·저널 장애·취소 실패 검증은 시작 대기 시계를 가속하고 관찰 시간을 줄였습니다. 실패 결과를 정상 완료로 처리하지 않습니다.

실제 거래소 주문/조회 및 Windows DB 변경: 0. 현재 PC에 추가 명령을 실행하거나 같은 조회를 반복할 필요는 없습니다.

`SOURCE_PROOF.json`에 고정 소스 커밋과 기존 파일 동일성, `VALIDATION.json`에 결과를 기록했습니다.
`source/`는 새 파일 6개이며 `SOURCE.patch`는 고정 기준 커밋에 대한 추가 전용 변경입니다. 전체 독립 실행 배포본이 아닙니다.
설계·한계는 `source/docs/TP_DURABLE_MANAGED_QUOTA.md`, 상세 모의 트레이스와 JUnit은 `evidence/`를 참고하세요.
