# DEMO 단일 실행 조립·종료 경로 — 개발 검토 자료

주문 예약 저널, 공유 요청 가중치 제어, 복제 클라이언트와 기존 청산 코디네이터를 하나의 실행 소유 객체로 조립했습니다.
기본 호출은 DB·파일·세션·HTTP 접근 전에 실행을 거부하며, 명시적인 모의 실행 코드에서만 구성할 수 있습니다.

- 기존 임대와 원장 범위를 확인하고 두 저장소를 읽기 전용으로 검사합니다. 초기화·복구는 하지 않습니다.
- 미완료 흐름/요청, 저장소 누락·불일치, 잘못된 범위·임대·기간이면 실행 객체 생성을 거부합니다.
- 실제 시작 직전에도 임대·기간·프로세스 잠금·미완료 공유 요청을 재확인합니다.
- 객체는 한 번만 실행할 수 있고, 성공·예외·취소 후 복제 클라이언트를 비활성화합니다.
- 종료 시 예산 객체를 먼저 차단한 다음 저널 잠금을 해제합니다. 종료 후 요청은 새 공유 예약 전부터 거부됩니다.
- 종료는 미완료 예약을 반환하거나 청산 완료로 처리하지 않습니다. 불확실한 실행은 다음 조립도 차단합니다.

호출자가 이미 획득한 임대와 원본 전송 경로는 호출자 소유입니다. 이 객체가 다른 임대를 해제하거나 공용 연결을 닫지 않습니다.
운영 CLI나 기본 실행 설정을 활성화하는 변경은 없습니다. 임의의 사용자 Python 전송 함수를 오프라인으로 강제하는 샌드박스도 아닙니다.

테스트 1,147개(중복 제외), mypy 152개 소스, Ruff, 네트워크 없는 Docker 스모크 통과.
실제 DB/파일로 기본 거부·임대 상실·기간 변경·미완료 보존·생성 실패 정리·취소·종료 후 차단을 검증했습니다.
최종 소스로 조립한 객체를 통해 TP 체결 청산과 부분 체결 후 위험 축소 청산을 모의 실행하고 전체 상태 확인까지 완료했습니다.
시작 대기를 가속하고 0.8초 관찰을 사용했으며, 요청 가중치 시계는 실제 시간을 사용했습니다. 새 300초 자연 관찰이나 거래소 검증은 아닙니다.

Windows 설치·Windows DB 변경·거래소 요청·실제 주문·거래 재개: 0.
실제 계정 ORDERS 사용량, 외부 IP 트래픽, 비용 상한 증명, 공유 파일의 외부 롤백 탐지 기준은 여전히 미완료입니다.
현재 PC에서 추가 조회나 거래 명령을 실행할 필요는 없습니다.
