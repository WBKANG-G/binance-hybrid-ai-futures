# 저장된 DEMO 확인 결과의 오프라인 일관성 검증기

필수 확인 진단·횟수·종료 상태·봉인 실패·원래 증명·트레이스 수치가 서로 맞는지 검사하는 별도 도구를 추가했습니다. 기존 가중치 검토기는 그대로이며 새 도구는 그 측정과 확인 보고서의 일관성을 함께 검사합니다. 원래 가중치 검토기의 기능 범위를 결함으로 바꿔 주장하지 않습니다.

종료 코드 0은 자료 일관성만, 3은 추가 검토 대상, 2는 잘못되거나 모순된 입력입니다. 어떤 경우도 거래소 현재 상태·금융 증명·파일 진위를 확인한 것이 아닙니다. 모든 출력은 execution_approved=false와 KEEP_PAUSED_REVIEW_ONLY입니다. 파일·DB·주문·승인 상태를 쓰지 않습니다.

중복 JSON 키·비정상 숫자·초과 중첩/크기·누락 필드·모순된 성공·허용되지 않은 승인 주장을 거부합니다. 미완료 예약이나 봉인 실패는 정상 완료 자료로 처리하지 않습니다. 오류는 경로·인수·알 수 없는 필드를 출력하지 않습니다.

현재 소스 회귀 검사 1,474개와 새 검증기 집중 검사 55개(회귀 검사에 포함), mypy 158개 소스, Ruff, 네트워크 없는 Docker 저장 자료 재검사가 통과했습니다.

금융 실행 코드는 이전 소스와 바뀌지 않아 새 청산 시뮬레이션을 반복하지 않았습니다. 해시를 검증한 이전 GitHub ZIP에서 원래 모의 TP·부분 체결·봉인 실패 자료 3개를 추출해 새 CLI로 재검증했습니다. 정상 2개는 코드 0, 봉인 실패는 코드 3입니다. 이전 청산 JUnit 3개는 출처를 표시한 재사용 기록이며 새 실행 결과로 계산하지 않습니다.

실제 계정 주문 사용량·외부 IP 여유·전체 요청 비용 상한은 미확인입니다. Windows 설치·Windows DB 변경·실제 거래소 요청·실제 주문·거래 재개는 수행하지 않았습니다. 현재 PC에서 추가 실행할 명령은 없습니다.
