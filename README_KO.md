# DEMO 전체 청산 증명 전 관측 유효기간 검사 — 개발 검토 자료

전체 청산 증명을 시작하기 전 비용 검사에서 사용량 관측의 유효기간을 확인하지 않는 공백을 수정했습니다. 5.001초·6초·60.002초의 수정 전 실패 3개를 재현했습니다. 개별 요청의 오래된 관측 차단은 이전에도 있었으므로 실제 초과 요청을 재현한 것은 아닙니다.

이제 신뢰 관측이 없거나 5초를 넘으면 추가 요청·예약·DB 쓰기 없이 증명 시작을 보류합니다. 기존 WATCH 시각 조회 경로에서 새 관측을 확보한 뒤 원래 비용 검사를 다시 적용합니다. 자동 조회·주문 재시도·가짜 관측은 추가하지 않았습니다. 시계 역행이나 조회 실패·429는 계속 중단하며 불확실한 전송 기록을 보존합니다.

검증: 테스트 1,288개, mypy 156개 소스, Ruff, 네트워크 없는 Docker 게이트 스모크 통과. 모의 TP와 부분 체결 청산은 원래 전체 청산 확인까지 통과했습니다. 시작 대기는 가속했고 관찰은 0.8초입니다. 새로운 300초 자연 관찰이나 거래소 검증은 아닙니다.

실제 계정 주문 사용량·외부 IP 여유·전체 요청 비용 상한은 미확인입니다. 운영 실행 기본값은 비활성입니다. Windows 설치·Windows DB 변경·실제 거래소 요청·실제 주문·거래 재개는 수행하지 않았습니다. 현재 PC에서 추가 실행할 명령은 없습니다.
