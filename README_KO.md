# 오프라인 검토 결과와 원본 바이트 연결

원본을 한 번 읽은 같은 바이트에서 검토 결과와 SHA-256·크기를 생성합니다. 저장한 결과를 원본과 다시 대조하는 --verify-receipt 모드를 추가했습니다. 원본 공백만 바뀌어도 기존 연결은 거부되고, 결과의 승인 값·타입·정책·버전 변경이나 다른 자료 혼합도 거부됩니다. 결과 JSON의 단순 키 순서·공백 변경은 허용합니다.

해시 일치는 서명·출처·현재 거래소 상태를 인증하지 않습니다. 원본과 결과를 함께 새로 만들 수 있는 사람은 새로 일치하는 쌍도 만들 수 있습니다. 모든 경우 실행 승인은 false, 다음 동작은 KEEP_PAUSED_REVIEW_ONLY입니다. 정상 검토 코드 0·추가 검토 코드 3은 발급·대조 후에도 유지되고 불일치는 코드 2입니다.

현재 소스 회귀 검사 1,502개와 검증기·연결 집중 검사 83개(회귀에 포함), mypy 158개 소스, Ruff, 네트워크 없는 Docker 대조가 통과했습니다. 새 연결 검사 28개가 포함됩니다.

금융 실행 코드는 바꾸지 않았고 새 청산 흐름도 실행하지 않았습니다. 해시를 검증한 이전 ZIP의 원래 모의 TP·부분 체결·봉인 실패 자료 3개에서 새 결과를 발급하고 실제 CLI로 대조했습니다. 이전 금융 JUnit 3개는 출처를 표시한 재사용 기록이며 현재 실행 수로 계산하지 않습니다.

실제 계정 주문 사용량·외부 IP 여유·전체 비용 상한은 미확인입니다. Windows 설치·Windows DB 변경·실제 거래소 요청·실제 주문·거래 재개는 수행하지 않았습니다. 현재 PC에서 추가 실행할 명령은 없습니다.
