사용자가 공유한 읽기 전용 후보: 이전 기준4998.99761493 USDT →11월6일 제안4998.95579884 USDT, 순입금 기준0. 최신 알려진 종료2026-11-05T10:21:53.432000UTC, anchor2026-11-05T10:22:12.883392UTC다. 새 날짜 경계는11월5일15:00UTC(11월6일00:00KST)다. 주간 기준/고점/기존 평가시각/요청/위험 상태 보존 조건이 확인됐다. 실제 계정 전체 export 검증은 아니며 운영자 확인과 서명 USDT 증거를 사용하는 기존 절차다.

ZIP을 새 폴더에 풀고 ADOPT-NOV6-DAY.cmd가 보이는 위치의 CMD에서 실행한다.

```bat
ADOPT-NOV6-DAY.cmd
```

기존 API에 보조 코드를 STDIN으로 전달한다. 새 서명 후보를 다시 조회해 위 날짜/금액/종료/anchor와 모든 보존 조건이 같은 경우에만 그 새 응답의 token을 메모리에서 기존 감사된 apply 명령으로 전달한다. 스크린샷 token을 복사하지 않는다. 후보가 바뀌면 적용하지 않고 중단한다. 현재 날짜가11월6일이 아니어도 중단한다.

DB 변경은 기존 명령을 통한 일간 기준일·기준금과 적용 감사 기록이다. 주간/고점/이력/과거 미해결 요청·위험 상태와 진입 정지를 보존한다. 이미11월6일이면 적용 없이 읽기 전용 준비 확인만 한다. 적용 후 다시 READ_ONLY_READY_ENTRIES_STILL_PAUSED와 원격 빈 계정/기준일 일치를 확인한다.

성공은 NOV6_DAY_ADOPTED_AND_READY_ENTRIES_STILL_PAUSED 또는 ALREADY_CURRENT_NO_APPLY다. BLOCKED_NO_AUTOMATIC_RETRY이면 출력 그대로 공유한다. apply_started/application_may_have_completed가 true이면 DB 적용 후 준비 검사만 실패했을 수도 있으므로 재실행/잠금 해제를 하지 않는다. 자동 재시도는 없다.

고정 날짜 갱신 작업ID는9a2edf63-14f2-4ec5-ac3c-d45d418da03b다. 이 ID는 아직 실행하지 않은 보호 worker 시험ID와 별개다. 앱/이미지/의존성/키 세션을 변경하거나 재시작하지 않으며 새 주문·프로세스 종료·메일 전송을 실행하지 않는다. 보호 worker 시험도 이 명령에서 자동 실행하지 않는다. 성공 결과를 공유한 다음 기존 승인 범위의 시험으로 이어간다.
