사용자가 11월 6일 수동청산 이후 11월 12일 현재까지 추가 거래, 입출금·이체, 보너스 지급, 계정 설정 변경이 없다고 확인한 내용을 이 날짜에 한정해 사용합니다. 기존 코드·저장소·시계 복구 완료 상태를 새로 설치하지 않습니다.

ZIP 안의 폴더를 바탕화면에 놓고 CMD에서 실행하세요.

```bat
cd /d "%USERPROFILE%\Desktop\windows-demo-storage-day-preview-20261112"
RUN_PREVIEW.cmd
```

이 단계는 DB·기준금액·저장 날짜를 변경하지 않는 미리보기입니다. 적용 명령은 포함하지 않습니다. 현재 저장된 11월 11일을 검증한 뒤 11월 12일 일간 기준 후보와 증거를 표시합니다. 주간 날짜는 11월 9일을 유지합니다. 정확한 자정 평가나 전체 종목 과거 거래 export를 확보했다고 주장하지 않으며 해당 항목은 false입니다. 출처는 사용자 무활동 확인과 서명된 USDT/청산/현재 노출 증거입니다.

## 확인 순서

1. 핵심 소스 55개와 제어 의존 파일 66개를 확인합니다. NORMAL·정지 상태·리스 없음과 수동청산, 11월 7/9/11일 영수증 체인, 저장소 설정·완료 영수증·바인딩을 검증합니다. 과거 영수증을 검사할 때 사본에서 알려진 저장소 키 4개만 제외하며 DB나 원본 영수증을 바꾸지 않습니다.
2. 공유 저널 시계와 약 70초 시작 대기 완료를 검증합니다. 주문/공유 저널이 미사용인지 확인합니다. 금융 계정/감사 이력, 모든 저장소 파일, 독립 PostgreSQL 체크포인트 전체를 해시로 기록합니다.
3. 기존 DEMO 키 세션을 프롬프트 없이 읽습니다. 세션이 없거나 만료됐으면 DEMO_CREDENTIAL_SESSION_UNAVAILABLE로 중단합니다. 자동 삭제·재등록이나 키 입력을 하지 않습니다.
4. 최대 48회 GET/75초로 제한한 읽기 경로에서 현재 계정 모드·잔고·전 종목 포지션·일반/알고 미체결 주문을 두 번 확인하고, 알려진 BTC 진입/청산의 서명 조회·체결 이력·청산 이후 수입 내역을 검증합니다. 정상 합성 테스트는 23회 HTTP 요청입니다. 418/429 응답이나 부족한 요청 여유에 재시도하지 않습니다.
5. 종료 시 금융 DB·저장소 파일·체크포인트가 그대로인지 비교하고 저장소 바인딩과 시계를 다시 검사합니다. 복구 백업과 intent.json도 해시 비교 범위에 포함합니다.

성공은 `manual_close_day_preview: OPERATOR_ATTESTED_DAY_PREVIEW_NO_DATABASE_CHANGE`입니다. `old_day_kst`는 2026-11-11, `proposed_day_kst`는 2026-11-12이며 일간 후보는 최신 검증 잔고를 따릅니다. 무활동/기존 잔고와 다르면 중단하며 임의로 기준값을 채우지 않습니다. `database_changed_by_preview`, `baseline_adoption_approved`, `execution_approved`, `orders_enabled`, `live_trading_enabled`는 false입니다. `storage_configuration_verified`와 각 보존 항목은 true여야 합니다.

이전 저장소 영수증의 해시가 원장 상태에 연결되어 있으므로 과거 날짜 적용 스크립트를 수정해 바로 실행하면 안 됩니다. 실제 적용은 이 미리보기 결과와 과거 영수증 보존을 확인하는 별도 절차가 필요합니다. 이번 ZIP은 그 적용이나 거래 재개 기능을 포함하지 않습니다. 출력이 성공해도 신규 진입은 계속 정지 상태입니다.

## 검증

격리 PostgreSQL·SQLite와 합성 서명 HTTP에서 14개 테스트가 통과했습니다. 실제 시계 복구 함수를 거쳐 생성된 원본 백업/intent 및 새 체크포인트가 미리보기 중 보존되는 연계 검사도 포함합니다. 계정 노출·계정 모드·체결 이력·수입 내역 변화, 요청 제한, 확인 누락, 날짜 오류, 시계 오류, 저장소/체크포인트 변경에 대한 중단을 검증했습니다. 네트워크 없는 Docker에서 LIVE 문맥·구버전 제어 소스·DB 불가 경로도 확인했습니다. 실제 사용자 PC와 거래소의 검증 완료를 의미하지 않습니다.
