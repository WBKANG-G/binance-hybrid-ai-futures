# 보호 중 worker 실제 종료 및 자연 리스 인계

실제 PostgreSQL과 별도 합성 거래소 서버, 로컬 WebSocket을 사용하는 격리 환경에서 실행 worker 프로세스를 실제 SIGKILL했다. 부모의 실행 코드·위험 정책은 변경하지 않았다. Windows DB와 실제 DEMO 계좌에는 추가 주문이나 장애를 가하지 않았다.

## 핵심 결과

집중 시험에서 child 종료 코드는 -9였고 finally 표식은 남지 않았다. 정상 종료·리스 반환으로 꾸민 시험이 아니다. worker는 실제로 합성 진입 한 건을 제출하고 SL·TP의 원래 서명 조회 검증을 마친 뒤 신규 진입을 정지하고 보호 준비 완료를 기록했다. 그 상태에서 종료했다.

종료 이후 기존 리스의 남은 시간은59.962초였다. 실제 monotonic59.969초를 기다렸고 lease_until은 변경되지 않았다. 보호 상태를31회 점검하는 동안 공유 거래소 fixture의 SL·TP는 NEW, 포지션 수량은0.0007 BTC로 유지됐다. 시험 시계 전진·리스 시간 단축·SQL 강제 만료를 하지 않았다.

| 확인 항목 | 집중 시험 결과 |
|---|---|
| 실행 프로세스 실제 강제 종료 | SIGKILL, 종료 코드-9, finally 표식 없음 |
| 원래 리스 만료 전 경쟁 리더 | 획득 거부 |
| 자연 만료 후 펜스 | 격리 시험 장부1→2 |
| 이전 소유자 부작용·갱신 | callback 실행 전에 거부 |
| 새 리더 신뢰 상태 | acquire 직후 stream/reconciled false, 새 진입 거부 |
| 새 세션 재검증 | 두 번째 실제 로컬 WebSocket 연결 및 원래 REST 대조 |
| 진입·SL·TP 식별자 | 기존 client/server 진입 ID와 보호 ID 그대로 회복 |
| 인계 전 전송 수 | 신규 진입 POST1, 보호 POST2; 중복 없음 |
| 후속 합성 포지션 정리 | 원래 비상 종료/VERIFIED_FLAT 후 리스 반환 |
| 실제 인증 거래소 호출 | 0 |

이 펜스1→2는 별도 시험 schema의 값이며 사용자 Windows 장부의 펜스 값이 아니다. 부모 HTTP 서버의 합성 거래소는 worker와 메모리를 공유하는 같은 프로세스가 아니므로 worker 종료로 주문 상태가 함께 사라지거나 새 fixture로 초기화되지 않았다. 다만 이 거래소 자체의 서버 종료/재시작을 검증한 것은 아니다.

## 검증 범위

가격80000, 수량0.0007, SL79600/TP80800의 합성 최소 수량 사례다. 원래 코디네이터의 예약·전송·보호·리스/펜스·WSS 진입 차단을 호출했고 원래60초 리스를 사용했다. 자연 만료 후 새 리더는 기존 주문을 조회·채택했으며 submit을 다시 호출해도 추가 진입 POST가 없었다. 일간·주간 기준금/정책/순이체를 보존하고 고점은 낮추지 않았다.

로컬 WebSocket은 ws:// 연결이며 TLS나 실제 Binance의 listen-key 동작을 수락한 시험은 아니다. 공유 거래소의 가격은 고정됐고 대기 중 TP/SL 트리거 체결은 발생시키지 않았다. 보호 주문이 검증된 뒤 신규 진입이 일시정지된 시점의 worker 종료이며, 진입 전송 중·미보호/부분체결 상태·모든 장애 시점을 포괄하지 않는다. 부모 감시·공유 거래소·PostgreSQL은 살아 있었다.

검증 수치: 전체1291개 통과(376.16초), 집중9개 통과(61.96초), 실패·건너뛰기 없음. Ruff 검사/포맷 검사 및 mypy115개 소스 통과.

## 남은 실제 수락 범위

실제 Windows DEMO 보호 포지션을 유지한 실행 worker 종료·인계는 아직 수행하지 않았다. 실제 부분체결 보호와 TP 트리거/SL 정리, 작업 중 실제 DB 서버 정지·전원 손실, 외부 긴급 알림 전달·장기 운영 검증도 별도다. 이번 합성 거래소 통합 결과로 실제 시장 수락이나 Phase4 전체 완료를 선언하지 않는다. LIVE/Phase5 전환은 없다.

이번에는 앱 코드 변경이 없어 사용자 Windows에서 재빌드·키 재입력·추가 주문을 할 필요가 없다. 현재 NORMAL/paused 상태와 이전 실제 미체결 종료 기록을 유지한다.
