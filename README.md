# Phase4: 검증된 거래소 시각으로 개인 이벤트 검사

ZIP을 새 windows-demo-event-clock-fix 폴더에 풀고 EVENT_CLOCK_START_HERE_KO.md를 읽으세요. 기존 Galaxybook의 hybrid-windows DB/영구 볼륨과 적용 기준을 유지합니다. 컨테이너 교체 뒤 메모리 키를 한 번 등록하고 주문 없는 복구 검토부터 실행합니다.

직전 실제 검증은 진입·SL/TP·청산을 확인한 뒤 ALGO_UPDATE의 PC 기준-6ms 시각 비교에서 실패했습니다. SDK는 거래소 시각 보정값을 쓰지만 이벤트가 PC 시각만 사용하던 차이를 보완합니다. 이전판에서 검증된6ms 보정에도 같은 실패가 나는 두 경우를 재현했고 수정판은 통과했습니다. 실제 사용자 원래 SDK 표본 자체가 보존됐다고 주장하지 않습니다.

기존 RTT/offset 검증을 통과한 시각 표본으로 서버 하한/상한을 구합니다. 확인된 상한 밖의 미래와 상한 기준30초 초과는 거부합니다. 구간 안의 불확실성은 실제 하한이 E에 도달할 때까지 기존1초 RTT 예산 안에서 기다려 다시 검사합니다. E를 바꾸거나 미래 허용 오차를 더하지 않습니다. SDK 네트워크·서명·주문 계약과 위험/보호/청산/기준/키 보관은 그대로이며 새 HTTP 호출도 없습니다.
